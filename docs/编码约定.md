# 编码约定

## 目录即架构

分包按「职责层 → 业务域」组织，目录结构直接反映模块依赖方向：

```text
backend/
└── com.evallab
    ├── api/          # REST 接口层：只做参数校验、编排、返回 Result<T>
    ├── core/         # 核心领域逻辑：不依赖 Web 与 SQL 细节
    │   ├── trace/
    │   ├── testcase/
    │   ├── eval/
    │   ├── scorer/
    │   ├── executor/
    │   ├── attributor/    # 阶段 3
    │   ├── review/        # 阶段 3，人工抽检与校准
    │   ├── baseline/      # 阶段 4，基线与回归门禁
    │   └── redteam/       # 阶段 6，红队用例与拦截率报告
    └── infra/        # 基础设施：db / llm / agent 适配
```

依赖方向单向：`api → core ← infra`。`core` 只定义端口接口（`*Store`、`AgentInvoker` 等），实现在 `infra`；
`core` 不反向依赖 `api`。命令行工具是独立 Maven 模块 `cli`，只通过 HTTP 调用平台接口，不引用 `core`。

## 命名

| 类型 | 规则 | 示例 |
|------|------|------|
| 实体 | 表名单数驼峰 | `eval_trace` → `EvalTrace` |
| Mapper | 实体名 + `Mapper` | `EvalTraceMapper` |
| Service | 业务名 + `Service` | `TraceService` |
| 接口层 | 业务名 + `Controller` | `TraceController` |
| DTO | 用途后缀 | `TraceCreateRequest` / `TraceDetailResponse` |
| 枚举 | 全大写下划线 | `SpanType.TOOL_CALL` |

- 表名统一 `eval_` 前缀，主键统一 `{实体}_id`（雪花 ID，`assign_id`）
- 时间字段统一 `created_at` / `updated_at`，类型 `DATETIME(3)`
- 布尔字段统一 `is_` 前缀，类型 `TINYINT(1)`

## 数据库

- 字符集 `utf8mb4`，排序规则 `utf8mb4_0900_ai_ci`
- 每张表必备：主键、`created_at`、`updated_at`
- 唯一约束显式命名：`uk_{表名}_{字段}`；普通索引：`idx_{表名}_{字段}`
- 逻辑删除按表启用：需要软删的表自带 `deleted TINYINT(1) DEFAULT 0`，实体加 `@TableLogic`。不开全局逻辑删除配置——开了它，没有该字段的表一旦触发删除就会报错
- 表结构变更以 SQL 脚本管理，放在 `docker/` 或后续的迁移目录，不做手改

## 接口

- 路径统一 `/api/{资源}`，资源名单数小写：`/api/trace`、`/api/testcase`
- 统一返回体 `Result<T>`：`code` / `message` / `data`。例外是给 CI 消费的机器接口（`/api/eval/gate`）：通过与否由 HTTP 状态码（200 / 422）表达，响应体直接是业务对象，不再套一层 `code`
- 异常统一由 `@RestControllerAdvice` 转换，Controller 不写 try-catch
- JSON 字段统一 snake_case（`spring.jackson.property-naming-strategy: SNAKE_CASE`），与 Trace 契约和数据库列名一致
- **查询参数名必须显式写**：`@RequestParam(name = "group_id")`。命名策略只作用于请求体与响应体的 JSON，`@RequestParam` 不做松弛绑定，省略 `name` 时只认 Java 参数名（`groupId`），前端传 `group_id` 会被静默忽略、筛选形同失效
- 时间统一 ISO 8601 输出，时区 `Asia/Shanghai`
- 响应中的雪花 ID（19 位）序列化为字符串：超出 JS 的 `Number.MAX_SAFE_INTEGER`，否则前端按 ID 编辑会打错行。注解 `@JsonSerialize(using = IdJson.class)`，新增对外响应 DTO 时照此处理
- 每个接口补 `@Operation` 注解，保证 OpenAPI 文档可读

## 配置

- 敏感信息只走环境变量，配置文件中用 `${VAR:default}` 占位
- 新增环境变量必须同步更新 `.env.example` 与 `docker/.env.example`
- 本地覆盖用 `application-local.yml`，不提交
- 容器内运行使用 `docker` profile；compose 通过环境变量注入连接信息，不用 `extra_hosts` 之类绕路
